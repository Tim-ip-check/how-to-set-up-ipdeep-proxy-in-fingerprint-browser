# 如何在指纹浏览器中设置IPDEEP代理IP？

IPDEEP提供全球高匿名代理IP服务，涵盖动态、静态、移动、数据中心IP等，做跨境业务的基本上都会使用到代理IP服务，下面小编以[比特指纹浏览器](https://www.bitbrowser.cn/)为例，为大家详细介绍如何在指纹浏览器中设置IPDEEP代理IP。

## 一、注册购买IPDEEP代理IP类型

IPDEEP代理IP提供动态、移动、静态、数据中心IP，支持多城市、多运营商节点，可根据业务需求购买合适的IP类型。

具体操作步骤：

1.进入[IPDEEP官网](https://www.ipdeep.cn/?extendid=zXY2LS)，注册登录后台。

![IPDEEP官网](/assets/图片1.png)

2.根据需求选择合适的代理IP（以静态住宅代理为例）

![选择静态代理ip](/assets/图片2.png)

3.购买完成点击【已购买静态住宅代理】

![已购买静态住宅代理](/assets/图片3.png)

## 二、本地切换外网访问

代理IP不支持国内使用，所以本地环境需要切换到外网去使用。可以使用市面上的第三方服务工具，比如 云梯、小火箭等

以[云梯](https://my.yunti2.net/auth/register?code=3f53adbf)工具为例：

### 进入云梯官网，注册登录后台。

按照自己的需求，选择合适的套餐购买开通。可选择下载云梯客户端 或 在第三方工具中进行配置

### 以 Flclash 为例，点击下载

![下载flclash](/assets/图片4.png)

注：云梯官网提供的 Flclash 下载地址版本比较旧，可以去 Flclash 官网下载：https://flclash.cc/en/download

### 复制 云梯 订阅 链接，导入flash ：

打开 flash 工具，点击左侧【配置】> 点击右上角“+”，粘贴刚才复制的订阅链接 > 点击提交。

![导入云梯订阅地址](/assets/图片5.png)

### 选择节点

点击左侧导航中的 代理 选项，在右侧选择您想使用的节点。

![选择节点](/assets/图片6.png)

### 开启代理

回到 仪表盘，打开「系统代理」与「虚拟网卡」，并点击左侧开关，即可开启代理服务。

![开启代理](/assets/图片7.png)

具体操作步骤，请参考：[https://github.com/Tim-ip-check/network-environment-guide](https://github.com/Tim-ip-check/network-environment-guide)

## 三、下载指纹浏览器（以比特指纹浏览器为例）

1.进入[比特浏览器官网](https://www.bitbrowser.cn/)

![比特浏览器官网](/assets/图片8.png)

2.[下载](https://www.bitbrowser.cn/download)适配电脑的操作版本

![下载比特浏览器版本](/assets/图片9.png)

3.注册登录比特浏览器，点击浏览器窗口，创建窗口【比特浏览器支持免费试用10个窗口环境】

![创建比特浏览器窗口](/assets/图片10.png)

4.滑到 代理设置 > 自定义代理 > 代理类型 > 输入你在IPDEEP平台购买的静态住宅IP

![输入你在IPDEEP平台购买的静态住宅IP](/assets/图片11.png)

5.代理主机对应服务器 > 代理端口对应端口号 > 代理账号对应 账号 > 代理密码对应 密码，复制即可。

![输入账密](/assets/图片12.png)

![点击保存](/assets/图片13.png)

6.输入完成，点击确定，IPDEEP静态住宅IP即绑定成功，点击打开按钮即可使用指纹浏览器。

![点击启动浏览器](/assets/图片14.png)
